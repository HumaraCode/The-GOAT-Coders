# The-GOAT-Coders

Download required Python libraries:
pip install streamlit pandas numpy scipy folium streamlit-folium pulp

To run code in terminal:
Step 1: Create an empty Python file and rename it (for eg: new.py)

Step 2: Copy paste the code in Project.py file in this Repository

Step 3:
Run the following command in terminal
python -m streamlit run new.py
(Replace new.py with local file name)
